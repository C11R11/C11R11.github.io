# 🎯 Master Checklist Unificado: Senior Systems & Backend Engineer

## 🏗️ 1. Gobierno del Proyecto, Negocio y Diseño (System Design)
- [x] Gestión, levantamiento de requerimientos y contraparte con Stakeholders (15+ años exp) [pucv, erp].
- [x] Planificación de proyectos, control de hitos y estimación de presupuestos/tiempos (MS Project) [pm].
- [x] Modelamiento de datos relacionales y optimización de persistencia empresarial (Sybase, MS Access) [db].
- [x] Diseño y validación de interfaces, pruebas de usabilidad, mapas de calor y mockups de UI [ux].
- [x] Integración de analítica avanzada en el core de sistemas de negocio (Google Analytics en ERP) [analytics].
- [x] Inicialización de repositorios organizacionales y definición de gobernanza documental [repo].
- [x] Redacción y aprobación de especificaciones de API (System Design Document - SDD vía OpenAPI/YAML) [sdd].

## 💻 2. Desarrollo Backend Core (El Foco Real de tu Laboratorio)
- [ ] Bootstrap de plataforma: Configuración de API moderna utilizando .NET 8 (o superior) Minimal APIs [net8].
- [ ] Implementación de Inyección de Dependencias (Lifecycles: Transient, Scoped, Singleton) y Clean Architecture [arch].
- [ ] Mapeo de datos empresarial y migraciones fluidas utilizando Entity Framework Core [efcore].
- [ ] Consultas de alto rendimiento y queries nativas mediante el uso de Dapper (Micro-ORM) [dapper].
- [ ] Implementación de Seguridad: Autenticación y Autorización basada en Tokens JWT [jwt].
- [ ] Creación de Middlewares globales personalizados para el manejo y formateo estandarizado de excepciones HTTP [middleware].

## 🧪 3. Calidad de Código y Pruebas (Indispensable para un Perfil Sólido)
- [ ] Diseño y ejecución de Pruebas Unitarias aisladas utilizando xUnit o NUnit [unittest].
- [ ] Implementación de dobles de prueba y aislamiento de dependencias de negocio usando Moq o NSubstitute [mocking].
- [ ] Configuración de análisis estático de código local enfocado en deuda técnica y seguridad [sonar].

## 📊 4. Observabilidad y Monitoreo Monolítico
- [ ] Implementación de logs estructurados (vía Serilog) para auditoría técnica y trazabilidad de errores [logs].
- [ ] Configuración de Health Checks nativos de .NET para el monitoreo del estado de la API y sus conexiones [health].

## 🛠️ 5. DevOps, Contenedores e Infraestructura como Código (IaC)
- [x] Administración y mantenimiento avanzado de servidores Linux empresariales (Acceso SSH, servicios) [linux].
- [x] Automatización mediante Scripting avanzado multiplataforma (Python, Bash, PowerShell) [scripting].
- [x] Virtualización y aislamiento local de entornos de desarrollo (Docker CLI, Docker Compose) [docker].
- [x] Orquestación de contenedores en la nube (Fundamentos y gestión básica de Kubernetes) [k8s].
- [x] Aprovisionamiento automatizado de infraestructura cloud (IaC con Terraform) [terraform].
- [x] Gestión de Terraform State remotos y seguros (Configuración de Backends en AWS S3) [tfstate].
- [x] Proveedores multi-cloud integrados en código de infraestructura (Providers de AWS, Azure y GitHub) [iac].
- [x] Operación avanzada en nubes públicas (AWS: EC2, S3, IAM, RDS, ECR, ECS; Azure: Virtual Machines) [cloud].
- [ ] Levantamiento local en Docker de bases de datos relacionales productivas (SQL Server o PostgreSQL) para el laboratorio [docker-db].

## 🚀 6. CI/CD y Automatización del Ciclo de Vida (SDLC)
- [x] Estrategias de ramificación, protección de ramas críticas y gobernanza de equipos/usuarios en GitHub [git].
- [x] Automatización de flujos de valor e integración continua (GitHub Actions para flujos SDLC completos) [ga].
- [x] Automatización de pruebas y empaquetado empresarial (Azure Pipelines para artefactos y testing) [azure].
- [x] Gestión de registros y repositorios privados de artefactos (AWS CodeArtifact, GitHub Packages) [artifacts].
- [ ] Optimización de imágenes de contenedor en pipelines mediante compilaciones Multi-stage de .NET [multistage].
- [ ] Configuración de Github Actions para la ejecución automatizada de pruebas unitarias en cada Pull Request [ga-testing].
- [ ] Despliegue e inyección automatizada de credenciales/imágenes en registros remotos (AWS ECR/ECS) al hacer merge [cd].

## 👥 7. Liderazgo Técnico y Calidad
- [x] Liderazgo directo de células de desarrollo de software (Coordinación de desarrolladores y diseñadores) [lead].
- [x] Mentoría técnica, transferencia de conocimiento y cultura de mejora continua en el equipo [mentor].
- [x] Comunicación fluida y técnica a nivel internacional (Inglés nivel B2 Upper Intermediate certificado) [english].
